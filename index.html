System Control

Control your aquaponic equipment remotely.

OPERATING MODE

AUTO controls the pump using the saved timer/soil settings. MANUAL follows the pump request.

MANUAL PUMP REQUEST
Pump Request
Used when MANUAL mode is selected.
The ESP8266 will stop the pump if water is not detected.
PUMP TIMER

In AUTO mode, the ESP starts a pump cycle at each interval. Water detection remains a safety requirement.

SOIL AUTOMATION

Optional AUTO protection: if soil drops below the start level, the ESP may run the pump until the stop level is reached. Timer can operate independently.

HUMIDITY AMPLIFIER
Amplifier Request
M11A0 follows the pump state in the ESP firmware.

If your ESP firmware links the M11A0 to the pump, this request is informational. The amplifier will run whenever the pump is running.
